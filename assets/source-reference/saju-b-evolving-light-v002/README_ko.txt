SaJu 비취 정령 — 국소적으로 변화하는 초록빛 v002

변경 내용
v001은 같은 빛 무늬의 좌표를 닫힌 경로로 옮겨 원형으로 도는 느낌이 있었습니다. v002에서는 시간에 따른 좌표 이동을 제거했습니다. 서로 독립적인 세 구름장이 고정된 좌표에 있고, 이들이 부드럽게 섞이며 각 부분의 빛이 생겨나고 사라집니다. 비취 바탕·형상·초록빛 색·강도2.0은 유지합니다.
시간에 따라 움직이는 것은 혼합 가중치뿐입니다. 원래 비취 기본 무늬와 각 구름장의 좌표·오프셋은 고정입니다. 단순한 전체 밝기 곱셈이나 전체 마스크 회전은 없습니다.

영상과 네이티브
- SaJu_Jade_EvolvingLight_12s_Preview_v002.mp4: 실제6초 루프 두 번,320×320/12fps/144프레임.
- SaJu_Jade_EvolvingLight_Loop6s_v002.mp4: 한 주기.
- SaJu_Jade_EvolvingLight_Keyframes_v002.jpg:0~5초 주요 시점.
- SaJu_Jade_Evolving_Light_v002_Final.blend: 편집 네이티브. 기본 허용되는 단순 시간 드라이버와 셰이더 수학 노드로 작동합니다. 보안 설정이나 자동실행 허용을 바꾸지 않았습니다.
- 기존 인사 모프 데이터는 남아 있지만, 이번 영상에서는 중립 자세로 고정했습니다.

루프/모양 검증
승인된 정적 원본의 동일 조건 렌더와 첫 프레임은 픽셀까지 같습니다.0초와6초, 영상의 두 반복도 픽셀까지 같습니다. 각 전환에서 다른 부위가 동시에 밝아지고 어두워집니다. 네이티브 셰이더에서 구운 혼합 가중치는13시점 모두 수식과 일치했습니다.
이 수치 검사는 연속성·구현 검증입니다. 움직임의 최종 자연스러움이나 사용자 디자인 승인을 대신하지 않습니다. 주요 실제 렌더를 검토했고 최종 평가는 영상으로 확인해야 합니다.

시간 혼합
6초를 세 구간으로 나눕니다. 구간 내부u를smoothstep으로 완만하게 만든 뒤, 현재장과 다음장의 가중치를cos(π/2·e),sin(π/2·e)로 정합니다. 제곱합1을 유지해 단순 평균 혼합 중 대비가 통째로 약해지는 것을 줄였습니다. 전체 화면의 총 밝기가 항상 동일하다는 보장은 아닙니다.
각 고정장과 원래 비취 노이즈의 좌표에는 시간 입력이 없습니다. 발광 마스크와 반사 분리 마스크는 같은 혼합 필드를 사용합니다.

런타임
runtime/에GLSL,JavaScript 기준 구현,3개 고정장을RGB에 묶은128³RGBA8 atlas/raw,원래 비취 기본색,명세와 테스트가 있습니다. 이전v001의단일필드u16자료와 호환되는 형식이 아닙니다. 새로운 runtime/README_ko.txt를 따르세요.
정적GLB는 절차적 재질 애니메이션을 자동으로 담지 않습니다. reference/의GLB는 형상/정적 재질 참고이며 기존 제한된 인사 클립이 남아 있습니다. 빛의 변화는 별도의 런타임 셰이더 연결이 필요합니다.
기존GLB의 정적으로 감쇠된 기본색/반사맵을 중복 적용하지 말고 동봉 원래 기본색과 동적 반사 분리를 사용합니다.

검증 범위
CPU10개,로컬MesaGLSL ES100/300각1117개 수치 검사 통과. 실제atlas24,696샘플의 좌표와고정장 값은 시간에 따라 변하지 않고 루프 끝 오차0입니다.256native probe와3,072혼합 비교의 필드 최대오차0.012061이며 유한 격자 근사입니다. 웹사이트·브라우저·모바일GPU·실제 앱 통합과 성능은 아직 검증하지 않았습니다.

다시 작업하기
.blend는 자체 편집/렌더 파일입니다. build_evolving_light_final.py는 별도 보존된 승인 정적 원본을 입력으로 사용하며 SAJU_APPROVED_SOURCE와SAJU_OUTPUT_DIR로 경로를 지정할 수 있습니다. --build-only는 소스만 만듭니다. bake_field_triplet.py는 동봉 flow_parameters_v002.json으로 atlas를 생성합니다.
이전v001과 중간 작업은 삭제하지 않았으며, 이 폴더는 검증된v002 전달용 파일만 묶었습니다. 사이트 배포나Drive 업로드는 하지 않았습니다.
